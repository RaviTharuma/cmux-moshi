# Glossary

| Term | Meaning |
|------|---------|
| **cmux-moshi** | Official cmux plugin for Moshi — friendly workspace names over Mosh/SSH |
| **cmux** | Terminal / agent workspace UI this plugin extends |
| **Moshi** | Mosh-based remote shell tooling paired with this plugin |
| **Mosh** | Mobile shell (UDP remote terminal) |
